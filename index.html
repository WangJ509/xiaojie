三個步驟，開始使用

  1. 下載並解壓縮

    取得 XiaoJie-2026.10.17.zip，解壓縮到「下載項目」。

  2. 執行安裝指令

    開啟「終端機」，貼上以下指令：

    sh ~/Downloads/XiaoJie-2026.10.17/install.sh
  3. 加入小傑輸入法

    系統設定 → 鍵盤 → 輸入方式 → 編輯 → ＋ → 繁體中文 → 小傑輸入法。

目前版本未經 Apple 公證，安裝腳本會移除下載包的隔離標記，並安裝至使用者的輸入法資料夾。安裝後若未出現，請登出再登入。

開始之前

你可能想知道。

Intel Mac 或 Windows 可以用嗎？

目前分享的安裝包適用 Apple Silicon Mac，搭配 macOS 14 以上。尚未提供 Intel Mac、Windows、iPhone 或 iPad 版本。

可以和小麥注音一起安裝嗎？

可以。小傑與小麥使用不同的輸入法識別碼及資料位置，可以同時安裝並隨時切換。

Caps Lock 切換中英沒有作用？

請先關閉 macOS 鍵盤設定中的「使用大寫鎖定鍵切換至及切換自 ABC」，再用小傑處理 Caps Lock 中英切換。短按 Shift 也可以切換。

安裝後沒出現，或某個 App 打不出字？

先確認已在系統設定加入小傑輸入法。若某個 App 無法輸入，先重新開啟該 App；安裝後仍未出現或沒反應，請登出再登入。

安裝包會包含作者的個人資料嗎？

不包含作者的選字學習記錄、使用者詞彙、錄音或 Gemini API key。你的學習記錄會保存在自己 Mac 的小傑資料夾。

如何回報問題或移除？

可到 GitHub Issues 回報問題，附上 macOS 版本、使用的 App 與重現步驟。移除時先從系統設定刪除小傑輸入方式，再移除 ~/Library/Input Methods/XiaoJie.app，並登出再登入。這不會刪除自己的學習記錄。
